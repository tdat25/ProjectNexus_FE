# ProjectNexus - Frontend

Repository chứa source code Frontend cho dự án **ProjectNexus**.

## Cấu trúc thư mục

- `frontend/`: Ứng dụng React + TypeScript + Vite + Tailwind CSS.

## Hướng dẫn chạy dự án

### 1. Cài đặt dependencies
```bash
cd frontend
npm install
```

### 2. Cấu hình môi trường
File cấu hình mẫu nằm trong `frontend/.env.development` và `frontend/.env.example`.

### 3. Chạy môi trường Development
```bash
npm run dev
```
Ứng dụng sẽ chạy tại: [http://localhost:5173](http://localhost:5173)

### 4. Build Production
```bash
npm run build
```
